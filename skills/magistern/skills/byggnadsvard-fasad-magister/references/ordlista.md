# Ordlista: fasad, profiler, stuck, mur och sten

Använd svensk term först, ge sedan synonym, latin/italienska där det finns, engelska och tyska.
Markera osäker översättning med "ca". Termer här är hantverks- och arkitekturhistoriskt vedertagna;
kontrollera mot SFV Putsarbeten, Stenhandboken och ICOMOS-glossaret innan de används i formella
utlåtanden (se kallbank-licens.md).

## Stuck och stuckatur

| Term | Betydelse |
|---|---|
| Stuck / stuckatur | dekor i gips, ofta med kalk, marmormjöl och lim; ordet från italienska *stucco* |
| Stuccolustro | polerad kalkputs med marmorkaraktär; vax/såpa som ytbehandling |
| Stuckmarmor (scagliola) | pigmenterad gipsmassa som imiterar marmor, polerad |
| Dragen list | profil dragen med mall (schablon) i vått bruk eller gips |
| Gjuten ornament | avgjutning i form, fästs med gips eller dymlingar |
| Modellerad stuck | fritt modellerad i vått material, ofta armerad |
| Kartusch | sköld- eller rullverksformad dekor, ofta med inskrift |
| Festong | hängande blom- eller fruktgirlang |
| Akantus | stiliserat bladornament från antiken |
| Rosett | cirkelrund blomdekor, ofta i tak eller på fris |
| Medaljong | rund eller oval relief |
| Pilaster | platt väggpelare med bas och kapitäl |
| Kapitäl | pelarens krön; ordningarna dorisk, jonisk, korintisk, komposit, toskansk |
| Fiberarmerad stuck (nyproduktion) | glasfiber-/polymerarmerat gips eller cement; ersätter ofta historisk gips utomhus |

## Natursten (vanliga svenska byggnadsstenar)

| Sten | Typ | Utseende | Vanlig användning |
|---|---|---|---|
| Gotländsk kalksten | sedimentär | ljusgrå till rödbrun, ofta fossil | socklar, trappor, fasadsten |
| Ölandskalksten | sedimentär | röd eller grå | golv, trappor, socklar |
| Övedssandsten (Skåne) | sedimentär | rödgul | fasader, ornament |
| Gotlandssandsten (Burgsvik) | sedimentär | grågrön, mjuk | skulptur, ornament, 1600–1800-tal |
| Granit (Bohus, Vånga, Stockholmsgranit) | magmatisk | röd, grå, grovkornig | socklar, trappor, portaler |
| Marmor (Kolmården, Ekeberg) | metamorf | grön, vit/grå | sockel, interiör, dekor |
| Täljsten | metamorf | grågrön, mjuk | portaler, ornament |
| Konststen / cementmosaik | konstgjord | ser ut som sten | 1900-talets socklar, omfattningar; förväxlas med sten |

Ursprung för en viss adress avgörs av arkiv eller Naturstensregistret, inte av utseende.
