# Skadeatlas: läsa åldrande på puts, stuck, mur och sten

Använd utredningskedjan: **observation → möjliga orsaker → vad som talar emot varje orsak → nästa
undersökning**. Ge aldrig åtgärdsråd direkt från en observation. Terminologi för sten enligt
ICOMOS-ISCS *Illustrated glossary on stone deterioration patterns* (flerspråkig):
https://www.icomos.org/public/publications/monuments_and_sites/15/pdf/Monuments_and_Sites_15_ISCS_Glossary_Stone.pdf/

## Vanliga observationer på puts och mur

| Observation | Möjliga orsaker | Talar emot | Nästa undersökning |
|---|---|---|---|
| Gröna alger, svart påväxt | långvarig fukt, skuggläge, otät avvattning | torr sydfasad: ovanligt | kontrollera stuprör, hängrännor, fönsterbleck |
| Saltskägg / saltutfällning (vit, luddig) | fukt som transporterar salter från mur eller mark | kan vara kalkutfällning från nytt bruk | smaka ej; prov för saltanalys, mät fukt |
| Bom (ihåligt vid knackning) | dålig vidhäftning, frost, för starkt bruk ovanpå svagt | lokal bom vid gammal lagning | knacka systematiskt, markera, dokumentera yta i m² |
| Flagande färg i sjok | tät färg på öppen puts, fukt bakom | om bara färg flagar utan puts: ytskiktsproblem | färgtyp (bränntest på lös flaga), fuktmätning |
| Frostsprängning (puts lossnar i skivor) | vatten i puts + frost; vanligt vid läckande stuprör, under fönster, vid sockel | | följ vattenvägarna uppifrån |
| Spricka: vertikal, genomgående | sättning, rörelse i stomme | hårfin ytspricka = krympning | sprickmätare, jämför över säsong |
| Spricka: nätformad (krackelering) | krympning i för fett eller för snabbt torkat bruk | | ytlig; kontrollera vidhäftning |
| Spricka: horisontell vid bjälklag | rörelse mellan material, järn som rostar | | sök armering, balkar, kramlor |

## Åldrande efter exponering (härledda riktvärden, inte garantier)

- Kalkfärg på kalkputs: ommålning typiskt 10–20 år beroende på väderstreck; putsen själv kan hålla
  över 100 år med underhåll.
- Tät organisk färg på kalkputs: skador ofta inom 10–15 år; varje lager förkortar putsens liv.
- Gipsstuck utomhus utan plåtavtäckning: ytskador inom 5–15 år i Stockholmsklimat.
- Sandsten (Gotland, Öved): mjuk, svartskorpa och alveoler i vindutsatta lägen; vittring kan vara
  millimeter per decennium i utsatta partier.
- Kalksten: lösningsvittring, blir mattare och grövre; svart skorpa under utsprång.
- Granit: nästan oförändrad; skador främst rost från dubbar och fogbruk som spjälkar.
Ange alltid att dessa är intervall från litteratur och erfarenhet; verifiera mot objektets historik.

## Fältprotokoll vid platsbesök

1. Fotografera hela fasaden per väderstreck, därefter detalj med måttstock.
2. Knacka systematiskt (rutnät om 1 m) och markera bom.
3. Notera vattenvägar: krön, gesimser, balkonger, bleck, stuprör, mark.
4. Dokumentera profiler med profilkam eller mått innan något rivs.
5. Ta lösa prov bara där det redan är löst; märk plats, höjd och väderstreck.
6. Skriv observationerna som observationer; lägg orsakshypoteser separat.
